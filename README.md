# Personal Portfolio Website

This is my personal portfolio website created using HTML and CSS.  
The website shows my skills, services, projects, work experience, and contact information in a simple and professional design.

## Features

- Responsive navigation bar
- Home section with social media links
- About section with skill bars
- Services section with hover effects
- Portfolio gallery section
- Client logos section
- Work experience timeline
- Statistics section
- Blog/Hobby section
- Contact form
- Google Maps integration
- Newsletter subscription section
- Footer with social media icons

## Technologies Used

- HTML5
- CSS3
- Font Awesome Icons
- Google Maps Embed

## Project Purpose

I created this project to improve my frontend development skills and practice building a complete portfolio website using only HTML and CSS.

## How to Run the Project

1. Download the project files
2. Open the project folder
3. Run the `index.html` file in any web browser

## Folder Structure

- `index.html` → Main HTML file
- `style.css` → CSS styling file
- Images folder → Contains all images and logos used in the website
